# Ibrahim Atatri - Career Fair Resume Website

A static HTML and CSS resume site for SWE 325/525, with my projects, education, experience, professional links, and downloadable resume. Expected graduation: May 2028.

## Local viewing

Open `index.html` in a browser. No installation, build step, or JavaScript is required. Relative paths support GitHub Pages repository hosting.

## Deployment

Use the fork's `main` branch and repository root in Settings > Pages. Record the real deployed URL and verification results in the assignment evidence after deployment succeeds.
